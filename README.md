# TY의 주식공부

반도체 중심 투자 공부를 위한 개인 대시보드입니다.

## 목적

매크로, 대표 지수, 비트코인, 반도체 핵심 종목, 리포트, 공시, 매매 기록을 한곳에서 확인합니다.

## 판단 흐름

1. 환율, 금, 유가, 비트코인, 지수로 시장 온도를 확인한다.
2. 메모리 병목과 AI 수요를 기준으로 반도체 산업을 해석한다.
3. 삼성전자, SK하이닉스, 마이크론을 비교한다.
4. 리포트와 공시로 근거를 확인한다.
5. 오늘의 판단과 다음 행동을 기록한다.

## 핵심 관심

- 삼성전자
- SK하이닉스
- 마이크론
- DRAM / NAND / HBM
- AI 시스템의 데이터 공급 병목

## 구성

- `index.html`: 메인 대시보드
- `assets/diagrams/pc-memory-structure.png`: 일반 PC 메모리 구조도
- `assets/diagrams/ai-memory-structure.png`: AI 시스템 메모리 구조도
- `rates.json`: 한국 기준금리 수동 관리 데이터
