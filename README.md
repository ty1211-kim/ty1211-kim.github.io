# TY의 반도체 노트

반도체 사이클을 구조와 데이터로 분리해 보는 개인 관찰 노트입니다.

## 목적

시세, 메모리 가격, 기업 자료, 기술 개념을 한 화면에 모아두되 서로 다른 성격의 데이터를 섞지 않습니다.

## 주요 구성

1. 읽는 기준: HBM, HBF, CXL, SOCAMM의 계층 분리
2. 시장 배경: 환율, 금, 유가, 지수, 비트코인, 한국 기준금리
3. 핵심 기업: 반도체 밸류체인 대표 기업의 주가와 시가총액
4. 메모리 가격: 칩 spot과 소비자가 proxy를 분리한 USD 가격 차트
5. 반도체 구조: PC 구조와 AI 시스템 구조 개념도
6. 확인 질문: 기술 병목, 가격 사이클, 반증 조건
7. 판단 기록: 관찰, 근거, 위험, 다음 행동
8. 확인 자료: 공식 원문과 데이터 출처

## 데이터 원칙

- 외부 시세 API는 실패할 수 있으므로 카드마다 원문 링크를 둡니다.
- 한국 기준금리는 `rates.json`으로 수동 관리합니다.
- 메모리 가격 차트는 `data/memory-watch-prices.json`을 읽습니다.
- 정확한 유료 원자료를 확보하면 HTML이 아니라 JSON만 교체합니다.
