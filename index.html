반도체 사이클을 구조와 데이터로 분리해 본다.

시세, 메모리 가격, 기업 자료, 기술 개념을 한 화면에 모아두되 서로 다른 성격의 데이터를 섞지 않습니다. 이 페이지는 추천 목록이 아니라 매일 확인하고 기록하는 개인 관찰 노트입니다.

읽는 기준

이 노트는 기술 계층, 데이터 출처, 가격 단위, 기록 형식을 먼저 고정하고 나서 종목을 봅니다.

기술 계층

HBM, HBF, CXL, SOCAMM은 같은 말이 아닙니다.

HBM은 GPU 인접 DRAM 패키지, HBF는 NAND 기반 보조계층, CXL은 인터페이스/메모리 풀, SOCAMM은 SoC 인접 LPDRAM 모듈로 분리합니다.

AI 병목

학습과 추론은 병목이 다릅니다.

학습은 GPU·HBM·Interconnect, 추론은 KV cache·용량·전력·저장 계층까지 같이 봅니다.

데이터 계층

시세, 공식 원문, spot, 소비자가를 섞지 않습니다.

실시간 시세는 API, 기준금리는 수동 파일, 메모리 spot은 전문 가격 데이터, 다나와 가격은 국내 소비자가 proxy로 구분합니다.

기록 규칙

판단은 관찰·근거·위험·다음 행동으로만 남깁니다.

좋은 기업과 좋은 진입 시점은 다릅니다. 매번 어떤 가정이 깨지면 생각을 바꿀지 기록합니다.

공식 원문 우선CXL, HBF, SOCAMM 같은 기술은 기업 블로그보다 표준·공식 발표를 먼저 확인합니다.
가격 단위 고정차트는 지수화하지 않고 USD 실가격으로 표시합니다. 시작점은 억지로 맞추지 않습니다.
개념도 경고아래 블록다이어그램은 실제 보드 배치도가 아니라 역할을 구분한 학습용 개념도입니다.
HBMGPU 옆에 붙는 초고대역 DRAM. 핵심은 대역폭, 수율, 패키징입니다.
HBFNAND 기반 고대역 플래시 보조계층. HBM 대체가 아니라 용량/저장 계층 보완입니다.
CXL Memory메모리 제품명이 아니라 CPU·장치·메모리 사이의 캐시 일관성 확장 인터페이스/풀입니다.
SOCAMMSoC 가까이에 붙는 LPDRAM 모듈. HBF도 CXL도 아닙니다.

오늘의 시장 배경

개별 종목보다 먼저 확인할 거시 변수입니다. 환율·금·유가·지수·비트코인·한국 기준금리만 분리해서 봅니다.

캐시를 먼저 표시하고 최신 가격을 갱신합니다.

핵심 기업

메모리·CPU·GPU·NAND 밸류체인의 대표 기업을 같은 카드 구조로 봅니다. 주가와 시가총액은 외부 시세 API와 보강 로직을 사용합니다.

메모리 가격 추이

칩 가격과 소비자 가격은 서로 다른 신호입니다. 두 차트를 합치지 않고, 단위와 출처를 분리합니다.

SpotDRAM/NAND 칩 가격

전문 가격 데이터가 기준입니다. 현재 파일은 공개 앵커값과 수동 입력으로 만든 대체 데이터입니다.

Retail국내 소비자가

다나와류 소비자가는 PC 조립 시장 체감가를 보는 proxy입니다. 메모리 업체 ASP와 동일하지 않습니다.

Manual교체 가능한 JSON

정확한 원자료를 확보하면 data/memory-watch-prices.json만 교체합니다.

차트 기준 차트 1: DDR4 16Gb · DDR5 16Gb · NAND MLC 512Gb급 USD 차트 2: DDR4 8GB · DDR5 16GB · NVMe SSD 1TB 다나와 대표가 USD 환산
데이터 사용 기준
1. 공식/전문 자료DRAMeXchange, TrendForce, 기업 IR, 공시를 우선합니다.
2. 단위 유지USD/chip, USD/module, USD/SSD를 섞지 않고 그대로 표시합니다.
3. 비정규화시작값을 100으로 맞추지 않습니다. 가격 레벨 자체를 봅니다.
4. 수동 입력 표시수동/보간 데이터는 결론이 아니라 질문 생성용으로만 사용합니다.

반도체 구조

블록을 누르면 역할, 대표 회사, 관련 종목, 학습 링크가 오른쪽에 표시됩니다. 그림은 실제 배치도가 아니라 계층 구분용 개념도입니다.

PC 구조: CPU, DRAM, GPU, NAND/SSD, VRAM의 역할을 분리해서 봅니다.

AI 구조: HBM, HBF, CXL Memory, SOCAMM을 서로 다른 계층으로 봅니다.

오늘의 확인 질문

매일 같은 순서로 질문합니다. 답이 없으면 관망으로 기록합니다.

기술 병목

  • 부족한 것은 GPU인가, HBM인가, 네트워크인가, 저장 계층인가?
  • 학습 병목과 추론 병목을 구분했는가?
  • CXL/HBF/SOCAMM을 같은 수혜주로 착각하지 않았는가?

가격 사이클

  • DDR4와 DDR5 가격 방향이 갈라지는가?
  • NAND/SSD 소비자가가 칩 가격을 따라 올라오는가?
  • 가격 상승이 다음 분기 ASP에 반영될 근거가 있는가?

반증 조건

  • 시가총액은 오르는데 현물가·수요 근거가 약해지는가?
  • 공시/실적에서 재고, ASP, capex 방향이 기존 가정과 충돌하는가?
  • 진입 사유와 손절/관망 사유를 분리했는가?
1. 정의약어를 외우기 전에 칩·모듈·인터페이스·저장계층을 분리합니다.
2. 구조개념도에서 데이터가 어디에 머물고 어디로 이동하는지 확인합니다.
3. 기업각 회사가 어느 병목에 노출되어 있는지 카드에서 확인합니다.
4. 기록관찰·근거·위험·다음 행동으로만 오늘 판단을 남깁니다.
